# Web Data Mining — Лабораторная работа №1

Консольное приложение для поиска страниц в архиве Common Crawl с использованием CDX-индекса и WARC-записей.

## Возможности

- поиск страниц по ключевым словам;
- ограничение поиска по домену;
- ограничение количества результатов;
- просмотр заголовка страницы;
- загрузка текста страницы из WARC;
- вывод результатов в виде таблицы.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Modesttttt/Web-Data-Mining.git
cd Web-Data-Mining
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его в Windows:

```powershell
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Общий формат команды:

```bash
python 1.py <ключевые слова> --domain <домен> --limit <количество>
```

Пример:

```bash
python 1.py Пермь --domain pstu.ru --limit 5
```

Для нескольких ключевых слов:

```bash
python 1.py Пермь университет --domain pstu.ru --limit 5
```

Для получения текста страниц используется параметр `--show-text`:

```bash
python 1.py Пермь --domain pstu.ru --limit 5 --show-text
```

## Аргументы

| Аргумент | Описание |
|---|---|
| `keywords` | Одно или несколько ключевых слов |
| `--domain` | Домен для поиска |
| `--limit` | Максимальное количество результатов, по умолчанию 10 |
| `--show-text` | Загружает WARC и показывает заголовок и фрагмент текста страницы |

## Как это работает

1. Выполняется поиск страниц через CDX-индекс Common Crawl.
2. Из результатов выбираются HTML-страницы со статусом `200`.
3. Без `--show-text` программа выводит найденные URL и даты архивации.
4. При использовании `--show-text` по данным CDX находится нужная WARC-запись.
5. Из WARC загружается только необходимый диапазон байтов.
6. HTML разбирается с помощью BeautifulSoup.
7. Из страницы извлекаются заголовок и текстовый фрагмент.
8. Результаты выводятся в таблицу.
