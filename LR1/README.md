# Web Data Mining — Лабораторная работа №1

Консольное приложение для поиска страниц в архиве Common Crawl с использованием CDX-индекса и WARC-записей.

Программа принимает одно или несколько ключевых слов, получает архивные записи через Common Crawl CDX API, загружает соответствующие WARC-записи и проверяет содержимое страниц. Результаты выводятся в табличном виде.

## Возможности

- поиск по одному или нескольким ключевым словам;
- проверка наличия всех переданных ключевых слов на странице;
- поиск по одному или нескольким доменам;
- домен `pstu.ru` используется по умолчанию;
- отдельный лимит результатов для каждого указанного домена;
- проверка нескольких последних доступных краулов Common Crawl;
- фильтрация CDX-записей по HTTP-статусу `200` и MIME-типу `text/html`;
- удаление дубликатов архивных записей;
- загрузка WARC по HTTP `Range` — только необходимого диапазона байтов;
- извлечение заголовка и текста HTML-страницы с помощью BeautifulSoup;
- подсчёт количества упоминаний каждого ключевого слова;
- вывод фрагмента текста вокруг найденного ключевого слова;
- статистика по количеству результатов, ключевым словам, датам и доменам;
- повторные попытки при временных сетевых ошибках;
- запуск исследовательских запросов из Jupyter Notebook.


## Запуск

Общий формат:

```bash
python commoncrawl_search_Danilov.py <ключевые слова> [--domain <домен> ...] [--limit <количество>] [--show-text]
```

Пример:

```bash
python commoncrawl_search_Danilov.py Пермь --domain pstu.ru --limit 5
```

Несколько ключевых слов:

```bash
python commoncrawl_search_Danilov.py Пермь ПНИПУ --domain pstu.ru --limit 10
```

Страница попадёт в результаты только при наличии всех переданных ключевых слов.

Несколько доменов:

```bash
python commoncrawl_search_Danilov.py Пермь ПНИПУ --domain pstu.ru chf.pstu.ru --limit 10
```

Лимит применяется отдельно к каждому указанному домену.

Показ фрагмента текста:

```bash
python commoncrawl_search_Danilov.py Пермь ПНИПУ --domain pstu.ru --limit 10 --show-text
```

## Аргументы командной строки

| Аргумент | Обязательный | По умолчанию | Описание |
|---|---|---|---|
| `keywords` | да | — | Одно или несколько ключевых слов |
| `--domain` | нет | `pstu.ru` | Один или несколько доменов для поиска |
| `--limit` | нет | `10` | Максимальное количество результатов на каждый домен |
| `--show-text` | нет | выключен | Показывает фрагмент текста страницы |

## Как работает программа

### 1. Получение списка краулов

Программа получает список доступных архивных индексов Common Crawl через `collinfo.json`.

Проверяются 15 последних доступных краулов:

```python
CRAWLS_TO_CHECK = 15
```

### 2. Поиск через CDX-индекс

Для каждого указанного домена выполняется запрос к CDX API.

Из результатов выбираются HTML-страницы со статусом `200` и MIME-типом `text/html`.

Количество запрашиваемых записей увеличивается относительно пользовательского лимита, чтобы часть неподходящих страниц можно было отфильтровать на следующем этапе:

```python
RECORDS_PER_CRAWL = 50
```

### 3. Удаление дубликатов

Перед обработкой WARC удаляются дубликаты по комбинации:

```text
URL + timestamp + digest
```

Записи одной страницы из разных дат сохраняются, поэтому результаты можно распределять по датам архивации.

### 4. Загрузка WARC

CDX-запись содержит имя WARC-файла, смещение `offset` и длину `length`.

На их основе формируется HTTP-запрос с заголовком:

```text
Range: bytes=<offset>-<end>
```

Таким образом загружается только нужный диапазон WARC, а не весь архивный файл.

Для чтения WARC используется `warcio`.

### 5. Обработка HTML

HTML разбирается с помощью BeautifulSoup.

Из страницы извлекаются:

- заголовок `<title>`;
- текст страницы.

Перед извлечением текста удаляются служебные элементы:

```text
script
style
noscript
header
footer
nav
```

### 6. Проверка ключевых слов

После извлечения текста программа проверяет наличие всех переданных ключевых слов.

Например:

```bash
python commoncrawl_search_Danilov.py Пермь ПНИПУ --domain pstu.ru
```

требует наличия на странице одновременно `Пермь` и `ПНИПУ`.

Для каждого подходящего результата также подсчитывается количество вхождений каждого ключевого слова.

### 7. Формирование результата

Для найденной страницы выводятся:

- URL;
- дата архивации;
- заголовок;
- при использовании `--show-text` — фрагмент текста.

Результаты форматируются с помощью `tabulate`.

### 8. Статистика

После таблицы выводится:

- количество найденных страниц;
- количество упоминаний каждого ключевого слова;
- распределение результатов по датам;
- распределение результатов по указанным доменам.

## Обработка сетевых ошибок

Запросы выполняются с таймаутом.

Для CDX-запросов предусмотрено до 3 попыток при временных HTTP-ошибках (`429`, `500`, `502`, `503`, `504`), таймаутах и ошибках соединения.

Для загрузки WARC также предусмотрено до 3 попыток.

Если отдельную запись получить не удалось, программа сообщает об ошибке и продолжает обработку остальных записей.

Common Crawl может временно ограничивать доступ при большом количестве запросов. В таком случае необходимо повторить запуск позже.

### 1. Пермь и ПНИПУ

Найти страницы с одновременным упоминанием города Перми и ПНИПУ и оценить распределение по доменам и датам.

Сравнение количества и характера упоминаний МГУ и МФТИ в одной и той же части веб-архива. Для сопоставимости используются одинаковые параметры поиска.

```bash
python commoncrawl_search_Danilov.py МФТИ --domain tabiturient.ru --limit 10 --show-text
```

### 4. Борис Пастернак + Пермь

Исследование контекста упоминания Бориса Пастернака в связи с Пермью, романом «Доктор Живаго» и Юрятиным.

```bash
python commoncrawl_search_Danilov.py "Борис Пастернак" Пермь "Доктор Живаго" Юрятин --domain teatr-teatr.com --limit 10 --show-text
```

## Важное замечание о `--show-text`

CDX-индекс содержит метаданные архивной записи, но не полный текст страницы. Поэтому для проверки наличия ключевых слов в содержимом страницы программа обращается к WARC.

Параметр `--show-text` управляет выводом текстового фрагмента пользователю: без него фрагмент не выводится, с ним добавляется отдельный столбец с фрагментом найденного текста.
